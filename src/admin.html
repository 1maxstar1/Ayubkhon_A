Реестр заявок

Отчёт, выгруженный с control.expertcenter.uz (.xls). Строки сопоставляются по номеру заявки: новые добавляются, существующие обновляются — та же заявка второй раз не появится. Ничего не удаляется.

Справочник цен (документы)

Пакет цен из документов — заключений экспертизы, прайс-листов, биржевых котировок, таблиц ставок (.json.gz). Эксперты видят цены активного пакета рядом со сметной ценой; ни одна цена не применяется без нажатия «Применить». Файл проверяется здесь, в браузере, и только потом отправляется на сервер.

Недельные котировки UZEX

Источник: UzEx — Недельные котировки (uzex.uz). Если единица в названии не указана — принята 1 тонна. Биржевые цены с НДС; в «Проверка цен» они показаны без НДС (÷ 1,12). Этот раздел отделён от «Справочник цен (документы)»: он не трогает пакеты, а загрузка пакета не трогает недели отсюда. Сайт хранит только последние 4 недели — каждая полученная неделя остаётся в этой базе.

Обучение

Что программа запомнила, чтобы учиться на вашей работе: решения по подсказкам и цены завершённых заявок. Здесь только количества — названий и цен нет. На подсказки это пока не влияет.

ЧтоСколько

Набор для обучения и точность нынешних подсказок

Каждая цена завершённых заявок спрашивается у справочника заново — на дату своей заявки, — и то, что программа предлагает сейчас, сравнивается с тем, что решили вы. Считается в этом браузере, наружу ничего не уходит. Новейшая пятая часть заявок — проверочная: на ней ничего не учится. В числах нет ни названий, ни цен — их можно скопировать и отправить разработчику.

Рабочие области

Заявки, открытые сотрудниками. Очистить — удаляются загруженные сметы, правки цен и экспорты, заявка возвращается «к началу» (регион сохраняется). Удалить — рабочая область удаляется полностью, заявка остаётся в реестре и может быть открыта заново.

Добавить заявку вручную

Для заявки, которой ещё нет в реестре. Если номер уже существует, обновятся только заполненные поля; при следующей загрузке реестра она тоже обновится по номеру. Те же действия есть в списке заявок (для администратора).
