Реестр заявок

Отчёт, выгруженный с control.expertcenter.uz (.xls). Строки сопоставляются по номеру заявки: новые добавляются, существующие обновляются — та же заявка второй раз не появится. Ничего не удаляется.

Рабочие области

Заявки, открытые сотрудниками. Очистить — удаляются загруженные сметы, правки цен и экспорты, заявка возвращается «к началу» (регион сохраняется). Удалить — рабочая область удаляется полностью, заявка остаётся в реестре и может быть открыта заново.

Добавить заявку вручную

Для заявки, которой ещё нет в реестре. Если номер уже существует, обновятся только заполненные поля; при следующей загрузке реестра она тоже обновится по номеру. Те же действия есть в списке заявок (для администратора).
